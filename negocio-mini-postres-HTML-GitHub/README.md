## Cómo subirla a GitHub

1. Creá un repositorio nuevo.
2. Elegí **Add file → Upload files**.
3. Subí todos los archivos y carpetas que están junto a este README.
4. Confirmá que `index.html` quede en la raíz del repositorio.
5. Presioná **Commit changes**.
